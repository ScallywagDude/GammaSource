# Hammer game data (FGD)

The 2003 `halflife2.fgd` (which includes `base.fgd`) used by GammaSource's Hammer, kept with the source so entity changes and their Hammer definitions travel together.

GammaSource additions are marked with a `// GammaSource:` comment. In Hammer, add `halflife2.fgd` under **Tools > Options > Game Configurations > Game Data files**; keep `base.fgd` in the same folder.
