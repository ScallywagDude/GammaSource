# Project TODO

This file mirrors the shared [README TODO list](README.md#todo). **Work on this list resumed on 27 October 2026 at the project owner's request.** Items marked "source fix awaiting a native rebuild and in-game test" are fixed in code but stay unticked until verified in game.

- ✅ **Find why killing any enemy crashes the whole engine.** Fixed and tested in game on 28 October 2026. A debugger caught it: the 2003 beta hands were deleted inside the viewmodel's DrawModel while the view renderer was still walking a list that held them, so the next draw called freed memory (`CViewRender::DrawRenderablesInList`). Hands are now retired during the frame and deleted after it, and all of them are dropped before the entity list is released at level shutdown. Testing also found a crash on map change: models loaded by the queued loader lacked the `studiohdr2` back link ("go fuck urself!" in the console), so their vertex data went to the wrong cache entry and `datacache` crashed. `UnserializeMDL` now adds the link. Tested with about 150 NPC kills, 8 map loads (including d2_prison_01) and 10 weapons, with no crash.
- ✅ **Fix the Worldcraft editor crash.** Fixed and tested on 28 October 2026. The address in the dialog (ending in 989F) is in `shaderapidx9.dll`, not Windows: after the graphics device was lost (editor minimised, or another D3D program such as the game taking the device) the editor drew through a dynamic mesh with no vertex buffer. Reproduced by starting the editor minimised; fixed in `materialsystem/shaderapidx9/meshdx8.cpp`. Also fixed: an uninitialised game configuration in the startup picker (the older dump, `CGameConfig::SetActiveGame`), and an undo crash after Merge Solids.
